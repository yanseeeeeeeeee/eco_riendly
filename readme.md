# EcoFriendly

**EcoFriendly** — мобильное Android-приложение для формирования экологичных привычек через систему заданий, баллов, уровней, стрика и достижений.

## О проекте

Современным пользователям часто не хватает простого и удобного инструмента, который помогал бы внедрять экологичные привычки в повседневную жизнь.  
**EcoFriendly** решает эту задачу с помощью игрового подхода: пользователь выполняет экологические задания, получает баллы, повышает уровень, сохраняет серию активных дней и получает достижения.

Приложение объединяет полезную социальную идею и понятный мобильный интерфейс, делая развитие экопривычек более интересным и наглядным.

## Актуальность

Проблема экологичного образа жизни остаётся актуальной, однако многим людям сложно сохранять мотивацию на постоянной основе.  
Приложение **EcoFriendly** помогает пользователю не просто читать об экологии, а постепенно внедрять полезные привычки в реальной жизни.

Актуальность проекта заключается в том, что он:
- мотивирует к экологичному поведению
- делает полезные действия регулярными
- показывает прогресс в понятной форме
- использует игровой формат для повышения вовлечённости

## Цель проекта

Создать мобильное приложение, которое мотивирует пользователей заботиться об окружающей среде с помощью системы заданий, наград и отслеживания личного прогресса.

## Задачи проекта

- разработать удобный интерфейс мобильного приложения
- реализовать регистрацию и авторизацию пользователей
- создать систему экологических заданий
- реализовать начисление баллов за выполнение заданий
- добавить систему уровней, достижений и стрика
- организовать хранение данных пользователя в базе данных
- обеспечить просмотр прогресса и результатов пользователя

## Функциональность приложения

В приложении пользователь может:
1. зарегистрироваться или войти в аккаунт;
2. просматривать доступные задания;
3. выполнять задания и получать за это баллы;
4. повышать свой уровень;
5. поддерживать серию активных дней;
6. получать бейджи и достижения;
7. отслеживать свой прогресс в отдельных разделах приложения.

## Логика работы приложения

Приложение построено на следующей логике:
- пользователь выполняет экологические задания;
- за задания начисляются баллы;
- на основе общего количества баллов рассчитывается уровень;
- за регулярную активность считается стрик;
- за выполнение определённых условий выдаются бейджи;
- все основные данные пользователя сохраняются в базе данных.
